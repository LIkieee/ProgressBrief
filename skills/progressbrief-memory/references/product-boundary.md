# Work Library product boundary

- **Capture** records a useful work fragment as a Worklog Entry, Knowledge
  Note, or both.
- **Remember** is an explicit request to preserve durable knowledge.
- **Recall** retrieves relevant professional details conversationally and does
  not generate HTML unless the user requests a report.
- **Curate** is a user-triggered review that proposes substantial changes and
  applies them only after approval.
- A **Workspace** is the privacy boundary, usually an employer, organization,
  or personal context. It is not a project, repository, or generic folder.
- Employer content defaults to internal, personal content defaults to private,
  and shareable is explicit. Archived Workspaces are excluded by default.
- Markdown remains the authoritative, human-readable Work Library format.
