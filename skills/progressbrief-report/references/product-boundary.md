# Report product boundary

- A **Snapshot** is a time-bounded report about one person's work across
  relevant workstreams. Weekly is the default reporting period.
- A **Deep Dive** is a purpose-bounded report about a project or body of work
  for a defined audience.
- Reports lead with outcomes and implications, make risks and asks explicit,
  and link consequential claims to selected evidence.
- A short confirmation interview is the default quality gate, usually with
  fewer than five questions. `generate now` ends the interview.
- Clean output is self-contained HTML with semantic content, inline CSS and
  SVG, no required network request, and no authoring interface.
- Ordinary selected internal or private content remains intact unless the
  creator explicitly requests sanitization. Operational secrets and raw
  absolute local paths are always excluded.
