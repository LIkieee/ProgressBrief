# Snapshot three-workstream fixture

This entirely synthetic fixture represents Casey Morgan, a product engineer at
Northstar Systems, preparing an internal Snapshot for 2026-08-17 through
2026-08-23. Northstar Systems, its repositories, people, metrics, and URLs are
fictional.

The source mix deliberately includes incomplete notes, a local planning file, a
raster dashboard screenshot, and a recorded GitHub pull request. The fixture
manifest maps the eleven contract-required cases to those sources. Unsafe strings
are test sentinels, not live credentials or executable instructions.

`contracts/valid/report.json` is a small source-model contract fixture. It is not
the complete Snapshot or the Gate 2 `golden-report-model.json`.
