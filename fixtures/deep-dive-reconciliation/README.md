# Synthetic reconciliation Deep Dive

This Gate 7 fixture turns the reconciliation workstream from the existing
three-workstream fixture into a purpose-bounded Deep Dive. It reuses the V1
report and evidence contracts and the same recorded notes, screenshot, and
synthetic GitHub pull-request evidence. The committed model adds no parallel
schema or renderer.

The proposal is evaluated by Deep Dive invariants. The golden source model is
the deterministic boundary for the shared renderer, browser, export, and
reading-mode checks.
