# Package two focused skills as one ProgressBrief product

ProgressBrief will ship as one repository and installable product package containing `progressbrief-report` for report generation and `progressbrief-memory` for Capture, Remember, Recall, and Curate. These workflows have different triggers, interaction rules, and success criteria, so separating them keeps activation and instructions focused while allowing them to share schemas and a companion CLI; the memory skill follows the validated report vertical slice.
